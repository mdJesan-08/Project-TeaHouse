## 📌 Project Overview

**Project Tea House** is a frontend web project designed to represent a tea brand website. The main goal of this project is to practice **Tailwind CSS** and build a **fully responsive layout**.

This project follows a **mobile-first design approach** and ensures compatibility across different devices.

---

## 🛠️ Technologies Used

- HTML5  
- Tailwind CSS  
- CSS Flexbox  
- CSS Grid  

---

## ✨ Features

- 📱 Fully Responsive (Mobile, Tablet, Desktop)  
- 🎨 Clean and modern UI design  
- 🧱 Layout using Grid & Flexbox  
- 🌈 Gradient backgrounds and shadows  
- ⭐ Featured Products Section  
- 💬 Customer Reviews Section
